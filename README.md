# Paris Apostolidis — Portfolio

Personal portfolio of Paris Apostolidis, Computer Science student at the University of Crete.
I spend my days learning why things work, not just how to build them.

**Live site:** https://parisap06.github.io/

## Currently diving into

- C++ Programming and Principles
- Computer Architecture
- Linear Algebra
- Discrete Mathematics

## Built with

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)
- Fraunces and Inter fonts (Google Fonts)
- Deployed on GitHub Pages with GitHub Actions

## Project structure

```text
/
├── .github/workflows/deploy.yml   # builds and deploys on every push to main
├── public/                        # static files (favicon, images)
├── src/
│   ├── pages/index.astro          # the site
│   ├── scripts/gradient.js        # animated WebGL gradient background
│   └── styles/global.css
├── astro.config.mjs
└── package.json
```
